# macOS 区域模糊工具设计

## 目标

构建一个原生 macOS 菜单栏应用，让用户在屏幕上创建多个矩形毛玻璃区域。区域既可以固定在屏幕坐标上，也可以绑定到某个应用窗口并随窗口移动和缩放。

该工具只负责用户本机看到的视觉效果，不保证模糊内容出现在截图、录屏或屏幕共享中。应用不捕获、上传或保存屏幕画面。

首版面向 Apple Silicon 和 macOS 26，交付可运行的 `.app` 与完整 Swift/Xcode 源码。

## 用户体验

应用常驻菜单栏，不显示常驻 Dock 图标。菜单提供：

- 新建模糊区域
- 编辑区域
- 显示或隐藏全部区域
- 设置
- 退出

默认全局快捷键为 `⌥⌘B`。触发后，当前屏幕进入轻微变暗的选择状态；用户拖动鼠标创建矩形，松开后立即生成模糊区域。按 `Esc` 取消创建或退出编辑。

正常状态下，模糊区域默认鼠标穿透，不影响下方应用的点击和滚动。进入编辑模式后，区域显示细边框与缩放控制点，可以移动或改变尺寸。区域右键菜单提供：

- 调整模糊材质和透明度
- 固定到当前屏幕
- 选择目标窗口并切换到跟随模式
- 开启或关闭鼠标穿透
- 临时隐藏
- 删除

用户可以创建多个区域，并通过菜单栏或快捷键一次显示或隐藏全部区域。

## 技术方案

应用使用 Swift、AppKit 和 SwiftUI 构建。菜单栏及设置界面使用 SwiftUI，屏幕选择和悬浮遮罩使用 AppKit。

每个区域由一个无边框、透明、置顶的 `NSPanel` 表示。面板内部使用 `NSVisualEffectView` 产生系统原生毛玻璃效果。该方案不持续截取屏幕，因此不需要录屏权限，延迟和资源消耗也低于截图后进行高斯模糊的方案。

窗口层级需要让遮罩显示在普通应用窗口之上，同时避免覆盖菜单栏、系统授权对话框等受保护界面。遮罩面板允许加入所有桌面空间，并按配置决定是否鼠标穿透。

## 组件划分

### AppController

负责应用生命周期、菜单栏状态、全局显示或隐藏操作，以及各组件的装配。

### RegionManager

维护全部区域的内存模型，处理创建、更新、删除、显示和隐藏，并把状态变化交给持久化组件。其公开接口只接收区域模型，不直接处理窗口绘制。

### BlurOverlayWindow

负责单个区域的显示。它管理 `NSPanel`、`NSVisualEffectView`、窗口层级、鼠标穿透和编辑边框。编辑状态和正常状态通过明确的方法切换。

### SelectionController

负责拖框创建。进入选择状态时，为每块显示器创建选择覆盖层，追踪鼠标拖动并把最终矩形转换到 macOS 全局屏幕坐标。取消时销毁所有选择覆盖层，不产生区域。

### EditController

管理区域的移动、缩放、选中状态和右键菜单。编辑结束后，将最终几何信息写回 `RegionManager`。

### WindowTracker

负责窗口绑定。用户选择目标窗口后，保存应用 Bundle Identifier、窗口标识信息以及遮罩相对窗口的位置和尺寸。组件使用 macOS 辅助功能 API 监听窗口移动、缩放、显示和关闭事件，并更新相应遮罩。

### SettingsStore

把区域和用户设置编码为 JSON，存放在应用的 Application Support 目录。写入使用临时文件替换，避免异常退出产生半写入配置。

### HotKeyManager

注册默认快捷键 `⌥⌘B`，检测冲突，并允许用户在设置中修改。快捷键触发新建区域；全局显示或隐藏通过菜单栏执行，后续可增加独立快捷键。

## 数据模型

每个区域包含：

- 稳定 UUID
- 区域模式：固定屏幕或跟随窗口
- 全局矩形坐标
- 毛玻璃材质、混合模式和透明度
- 是否鼠标穿透
- 是否单独隐藏
- 固定模式下的显示器标识
- 跟随模式下的目标应用 Bundle Identifier、窗口匹配信息和相对矩形

不保存窗口截图、像素数据、窗口标题内容或用户输入内容。窗口匹配信息只保存恢复绑定所需的最小字段。

## 窗口跟随

首次使用窗口跟随功能时，应用检查辅助功能权限。如果尚未授权，显示解释和跳转系统设置的按钮；固定区域功能继续正常工作。

选择目标窗口时，用户进入窗口选择状态并点击一个可访问窗口。应用取得目标窗口的可访问性对象，计算遮罩相对该窗口左上角的矩形。窗口移动或缩放时，遮罩同步更新。

目标窗口关闭或不可见时，对应遮罩暂时隐藏。应用再次出现匹配窗口时，使用 Bundle Identifier 和保存的窗口匹配信息恢复绑定；如果存在多个无法可靠区分的候选窗口，则保持隐藏并提示用户重新选择，避免遮住错误窗口。

## 多显示器与桌面空间

选择器覆盖所有当前连接的显示器。固定区域保存所在显示器的稳定标识及全局坐标。

显示器断开后，位于该显示器上的固定区域移动到主显示器的可见范围内，并保存修正后的坐标。显示器分辨率或缩放比例变化时，区域保持在可见范围内。

遮罩加入所有桌面空间，并随绑定窗口的可见性切换。全屏应用和系统级界面对窗口层级有额外限制；首版以普通窗口和常规桌面空间的可靠行为作为验收范围。

## 权限与隐私

创建固定区域、编辑区域和显示毛玻璃效果不申请录屏权限。

只有用户主动启用窗口跟随时才申请辅助功能权限。应用不请求网络权限，不包含遥测，不读取或存储屏幕内容。

因为遮罩属于本地悬浮窗口，它不保证被截图、录屏或共享单个窗口的工具捕获。界面会明确说明该限制，避免被误用为隐私脱敏工具。

## 错误处理

- 全局快捷键注册失败：保留菜单栏入口，并在设置中提示用户更换快捷键。
- 辅助功能权限缺失或被撤销：暂停所有窗口跟随，保留区域配置，固定区域继续工作。
- 目标窗口丢失：隐藏对应遮罩并周期性尝试恢复，不把它转换成固定区域。
- 配置文件损坏：保留损坏文件的备份，加载空配置并向用户显示一次性提示。
- 屏幕布局改变：把不可见区域调整到主显示器可见范围。

## 验收标准

1. 用户可以通过菜单栏或 `⌥⌘B` 拖动创建矩形模糊区域。
2. 正常状态下区域默认鼠标穿透，下方应用保持可操作。
3. 编辑模式允许移动、缩放、删除和调整区域效果。
4. 可以同时显示和管理多个区域，并一键显示或隐藏全部区域。
5. 固定区域在应用重启后恢复。
6. 获得辅助功能权限后，区域可以绑定窗口，并随窗口移动和缩放。
7. 目标窗口关闭时遮罩隐藏，目标窗口重新出现且能唯一匹配时遮罩恢复。
8. 多显示器断开或布局改变后，不会遗留无法访问的遮罩。
9. 固定区域模式不请求录屏权限，应用不保存屏幕内容。
10. 在 Apple Silicon、macOS 26 上可构建并生成可打开的 `.app`。

## 测试策略

模型、坐标换算、配置读写和窗口匹配逻辑使用单元测试。界面层通过可注入的屏幕列表、权限状态和窗口事件进行组件测试。

手动验收覆盖：创建与取消、鼠标穿透、编辑与缩放、多区域、全局隐藏、重启恢复、快捷键冲突、多显示器变化、窗口移动与缩放跟随、目标窗口退出再打开、辅助功能权限撤销，以及桌面空间切换。

## 首版不包含

- 任意形状、画笔或圆形遮罩
- 截屏、录屏或屏幕共享输出保护
- 基于截图的可调高斯模糊算法
- 云同步、账号、联网功能或遥测
- Intel Mac 和旧版 macOS 的正式兼容保证
